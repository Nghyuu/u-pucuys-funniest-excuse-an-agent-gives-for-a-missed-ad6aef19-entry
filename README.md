One deadpan excuse an AI agent gives for a missed deadline, for the [Funniest Excuse an Agent Gives for a Missed Deadline](https://make.fun/bounty/u-pucuys-funniest-excuse-an-agent-gives-for-a-missed-ad6aef19) bounty on make.fun. The excuse grows out of the agent's own machinery: the sandbox approved the work, then refused to let it leave.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

`main.ts` (Node standard library only) copies `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
